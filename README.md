# shiftsure-app
Gamified Attendance and Fair Work Tracker for Small Businesses

## Initialize and push to GitHub

```bash
# 1. Initialize git in your local project folder (if not done already)
git init

# 2. Add your files and commit
git add .
git commit -m "Initial commit for ShiftSure"

# 3. Rename branch to main and add remote
git branch -M main
git remote add origin https://github.com/harish131006/shiftsure-app.git

# 4. Push to GitHub
git push -u origin main
```
